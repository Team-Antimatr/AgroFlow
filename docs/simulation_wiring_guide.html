💡 Why & How Potentiometers Simulate Sensors in Wokwi Core Simulation Concept

In Wokwi.com, proprietary probe modules (like physical water TDS probes and soil capacitance prongs) do not exist as stock components. However, both real physical sensors and potentiometers work identically at the electrical level: they both output a variable 0V to 5V analog voltage into the Arduino's ADC pins (A0 and A1).

🧪 Potentiometer 1 → TDS Water Sensor (Pin A0)

In real water, higher dissolved salts increase electrical conductivity, shifting voltage. In Wokwi, turning this knob simulates varying water salinity:

  • Knob at Left (0V – 1.5V): 0 – 500 ppm → Safe / Clean Water → SG90 stays at 0° (Bypass).
  • Knob turned Past Halfway (> 1.7V): > 500 ppm (e.g. 850 ppm) → High Salinity Alert → SG90 immediately rotates to 90° (Divert to Bio-Filter)!
int tdsPPM = map(analogRead(A0), 0, 1023, 0, 1500);
if (tdsPPM > 500) { servoDiverter.write(90); }
🌱 Potentiometer 2 → Soil Moisture Sensor (Pin A1)

Real soil probes change impedance based on moisture content. In Wokwi, turning this knob directly simulates soil hydration percentage:

  • Knob at Low (Dry Soil, < 30%): System permits irrigation cycle; pump is triggered.
  • Knob at High (Wet Soil, ≥ 60%): Safety Lock Activated! System aborts pump to prevent root waterlogging & rot.
int soilMoisture = map(analogRead(A1), 0, 1023, 0, 100);
if (soilMoisture >= 60) { abortPumpRelays(); }
✨ Zero Code Change for Real Hardware: When moving from Wokwi to physical Arduino Uno, the code remains identical because the real TDS sensor signal wire also plugs directly into Pin A0 and outputs the exact same 0–5V analog range!
